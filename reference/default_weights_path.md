# Path to Model Weights

The default path for EWSNet model weights to use. Is the location of the
EWSmethods package. If you'd like to instead set your own path,
[`ewsnet_reset()`](https://duncanobrien.github.io/EWSmethods/reference/ewsnet_reset.md)
contains the argument `weights_path` to do so.

## Usage

``` r
default_weights_path()
```

## Value

No return value, called for reference.
